# muxue-meter

**日本語** | [简体中文](README.zh-CN.md) | [English](README.en.md)

Claude Code の mod：入力欄の上に使用量のステータスバーを 1 行表示し、詳細パネルも開けます。

```
⚡ opus-5-5 97.7 tok/s · セッション $2.29 · 今日 $2.10 · キャッシュ命中 97.65%   隠す  簡易  詳細
```

- 右上の「隠す / 簡易 / 詳細」で表示を切り替え：隠す はボタンだけ、簡易 はステータスバー 1 行、詳細 はその下に詳細カード
- 詳細ウィンドウ（「詳細」を押すか `/meter` を入力。入力欄の上に開き、サイドバーは使いません）：1日 / 7日 / 30日、アカウントで絞り込み、モデル別の割合、平均 TPS、日別の金額。token は K / M / B 表記か正確な値で表示
- 利用枠の推定（詳細カード内）：5 時間 / 週の上限の使用率から枠の大きさを逆算します。`枠 ≈ ウィンドウの最初の読み取り以降に記録した API 換算額 ÷ その後の使用率の増分`（増分が 5 ポイントに達してから表示）。「5時間の予測枠」「週の予測枠」として表示し、アカウントごとに別々に計算します。増分が足りない間は前回の推定を表示します。CLI セッションの `~/.claude.json` が実際に使っているアカウントと食い違う場合は、週のリセット時刻で見分けて正しいアカウントに記録します
- ステータスバーと詳細カードは使える幅に合わせて変わります：幅が足りれば全部表示し、狭いと自動で短くなります
- UI は 10 言語に対応。既定はシステムの言語に合わせ、詳細カードの右上で手動でも切り替えられます
- 金額は API 単価で換算した額です。料金表は `hooks/register.js` 冒頭の `PRICES`（2026-10 の公式価格と照合済み）にあり、新しいモデルが出たら手動で更新します。Opus 5 系の fast モードは 2 倍で計算します。Haiku 5.5 はプロンプトが 10 万トークンを超えるリクエストを高い方の単価で計算し、`haiku-5-5@long` として別に表示します
- データは `~/.claude/plugins/store/` に保存され、このリポジトリには入りません。各セッションは自分のキーだけに書き込むので、複数のセッションを並行しても上書きし合いません
- アカウント：アカウント uuid の SHA-256 先頭 8 文字で区別します（デスクトップ版は環境変数 `CLAUDE_CODE_ACCOUNT_UUID`、CLI は `~/.claude.json` から取得）。uuid そのものは保存しません。どのアカウントか分かるように、伏せ字にしたメールアドレス（例：`al…@example.com`）を保存します。名前は変更できます
- デスクトップ版でアカウントを切り替えた場合、反映されるのはその後に作成したセッションだけです

## 動作環境

Claude Code の mods（function hooks）機能が必要です。v2.1.286 で開発・テストしています。デスクトップアプリの Code タブと CLI の両方で表示されます。WSL のセッションには対応していません。

プラットフォーム：Windows は実機でテスト済み。macOS / Linux は自動テスト（`$HOME` のパスを模擬し、CI で 3 つのプラットフォームで実行）でカバーしていますが、**Mac の実機ではまだテストしていません**。問題があればスクリーンショットを添えて issue を立ててください。

## 試す

```bash
git clone https://github.com/muxueliunian/muxue-meter.git
cd muxue-meter
claude --plugin-dir .
```

## 開発

```bash
claude plugin validate .
```

```bash
claude plugin test .
```

テストは `tests/` にあり、各ケースを terminal と desktop の 2 種類の UI で実行します。

## 更新

プラグインは GitHub 上の `plugin.json` を最大 6 時間に 1 回確認します（結果は全セッションで共有）。新しいバージョンがあると、ステータスバーに `⬆ 新バージョン vX.Y.Z` と表示されます。通知だけで自動更新はしないので、プラグインのフォルダで次を実行してください：

```bash
git pull
```

そのあと `/reload-plugins` を実行します。ネットワークで確認したくない場合は、`hooks/register.js` 冒頭の `UPDATE_URL` を空文字列にしてください。

## 集計の定義

- 実質入力 = キャッシュ読取 + キャッシュ書込 + 非キャッシュ入力。モデルが実際に読み込んだ量です
- 非キャッシュ入力は API の `input_tokens`：最後のキャッシュブレークポイントより後の部分で、Claude Code では通常 1 回あたり数 token しかありません
- 出力には思考（thinking）token を含みます

## 既知の制限

- インストール後の使用量だけを集計します
- 利用枠の推定は、このプラグインが記録した CLI / アプリの使用量だけで計算します（claude.ai のウェブ版などは含みません）。API 価格で換算するため、モデルの割合が変わると推定値もずれます
- TPS は `output_tokens ÷（最初のコンテンツチャンクから応答終了までの時間）`。生成が 0.2 秒未満、または 20 token 未満のリクエストは含めません
- 0.4.0 より前はプラグイン名が `usage-panel` でした。初回起動時に古いデータを自動で移行します
